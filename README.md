## Polymorphism

Polymorphism in object-oriented programming (OOP) is a feature that enables a 
superclass to engage with its subclasses. The superclass is the parent; it can 
interact with subclasses, which are its children. Object-oriented programming 
offers features that facilitate a direct method for interacting with a group of 
objects, irrespective of their specific class origins."Poly" means "many," and 
"morph" means "form," so "so many forms" refers to methods.

## Strategy Pattern

The Strategy Pattern is used to define different algorithms for calculating service
charges for each type of bank account, while keeping the main account logic flexible
and reusable.

We extracted all service-charge logic from the account subclasses into dedicated 
strategy classes:

- **OverdraftStrategy** for Chequing
- **ManagementFeeStrategy** for Investment
- **MinimumBalanceStrategy** for Savings

## Observer pattern

In this application, the Observer Pattern is used to create a one-to-many relationship 
between bank accounts (Subjects) and clients (Observers).

-Each BankAccount object (such as ChequingAccount or SavingsAccount) acts as 
the Subject. It maintains a list of clients who are observing it.

-Each Client object acts as an Observer, which means it “subscribes” to updates 
from the account.

This design allows the account notifies allthe attached observers(clients) and 
clients can receive notification by email, text, or updating their account summary.

## Event-Driven Programming Paradigm

-The Event-Driven Programming Paradigm is central to how this client lookup 
application operates. It structures the flow of the program around user 
interactions and system-generated events, rather than a linear sequence of 
instructions. 
-The PySide6 event loop continuously listens for events generated by the 
user interface (such as button clicks, table selections, and window actions)
and then calls the appropriate handler functions (slots) in response.

For example:
•  lookup_button.clicked.connect(self.on_lookup_client)
connects the button click to the method that performs a client lookup.
•  client_number_edit.textChanged.connect(self.on_text_changed)
responds dynamically as the user types.
•  account_table.cellClicked.connect(self.on_display_account_details)
triggers account detail display when a table cell is clicked.
