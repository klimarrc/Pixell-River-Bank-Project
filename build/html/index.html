class bank_account.bank_account.BankAccount(account_number: int, client_number: int, balance: float, date_created: date)¶

Bases: Subject, ABC

Abstract base class representing a bank account.

Inheritance:

  • Subject: Enables observer registration and notifications.

  • ABC: Enforces abstract methods for subclass implementation.

Subclasses (Chequing, Investment, Savings) inherit these observer capabilities.

Constants:

LOW_BALANCE_LEVEL (float): Threshold for low balance warnings. LARGE_TRANSACTION_THRESHOLD (float): Threshold for large transaction alerts.
